🔑 ログイン・ログアウト
アプリの使い始めと終わり方
ログイン手順
① 職員ID（4桁の数字）を入力
② パスワードを入力 → 「ログイン」をタップ
③ 初期パスワードは 職員IDと同じ です。ログイン後すぐに設定から変更してください
ログアウト・自動ロック
ログアウトは 設定 → 「ログアウト」ボタン
10分間操作がないと 自動ロック されます（8分で警告表示）
端末を離れる際は必ずログアウトしてください
パスワード変更
設定 → 「パスワード変更」から個人で変更できます
新しいパスワードは 英字と数字を含む6文字以上 が必要です
🏠 ホーム画面
最初に表示されるダッシュボード
ログイン者名の表示
ダッシュボードヘッダー右端に 現在ログイン中の職員名 が表示されます
端末を共有している場合に、誰のアカウントで操作中か一目で確認できます
🔔 確認事項（アコーディオン）
ダッシュボード上部の「🔔 確認事項」パネルに要注意情報が集約されています
パネルヘッダーをタップすると折りたたみ／展開できます。件数バッジで全体把握が可能です
優先順位：🌡️ バイタル異常 → 🚨 インシデント → 🩺 医師指示 → ⚠️ バイタル未記録 → 🚽 排便3日以上
いずれも該当なしの場合は「✅ 現在確認が必要な事項はありません」と表示されます
🏢 事業所から入力
ダッシュボード上部の紺色カードから サ高住・小多機・デイ・訪問介護 を選んでタップ
選択した事業所の利用者一覧が開き、サービス選択済みの状態で記録入力できます
例：デイ出勤時 → 「☀️ デイ」タップ → 利用者選択 → バイタル・食事入力
クイックアクセス
👥 利用者一覧 / 📅 予定表 / 📣 申し送り / 👁 巡回チェック へのショートカット
巡回チェックでは 全施設 / 居住 / デイ / 小多機 / 訪問 でフィルタリングできます
👥 利用者一覧・詳細
利用者情報の確認と記録入力
一覧の使い方
利用者はあいうえお順で表示。上部の検索バーで名前・かなで絞り込めます
カードをタップ → 詳細画面へ移動
ステータスバッジ
利用者カードに要注意バッジが自動表示されます
🌡️ バイタル未　本日バイタルが未記録の利用者
🚽 X日　排便から3日以上経過（または排便記録なし）の利用者
バッジは自動で更新されます。ダッシュボードの確認事項とも連動しています
今日のサービスを選択（新機能）
詳細画面の「記録入力」エリアに サ高住 / 小多機 / デイ / 訪問介護 のサービスボタンがあります
今日利用するサービスをタップして選ぶと、そのサービス用の入力ボタンが表示されます
登録済みサービスは濃く、未登録は薄く表示されます（タップは常時可能）
⚙ サービス設定（新機能）
サービスボタン右端の ⚙ をタップ → 利用するサービスをチェックして保存
小多機は「通い・泊まり・訪問」を包括するサービスです。デイサービスとは別に登録してください
記録ボタン（サービス別）
サ高住：バイタル / 食事・飲水 / 排泄 / 経時記録 / 体重 / 申し送り
小多機・デイ：上記＋来所/退所
訪問介護：訪問介護記録 / 経時記録 / 申し送り
バイタルサマリー
異常値は 赤字 で表示されます
正常範囲：血圧 90〜140 / 40〜85　脈拍 50〜100　体温 35.5〜37.2℃　SpO2 95%以上
フェイスシート
右上「📋 フェイスシート」ボタンで既往歴・緊急連絡先・担当医などを確認・編集できます
🌡️ バイタル入力
血圧・脈拍・体温・SpO2の記録
入力項目
収縮期血圧 / 拡張期血圧 / 脈拍 / 体温 / SpO2 / 意識レベル
空欄でも保存できます（測定できなかった項目はそのままで）
🎤 音声入力の使い方
「音声で一括入力」ボタン → マイクに向かって話すだけで自動入力
例：「血圧130の80 脈拍72 体温36.5 SpO2 98 清明」
実施日時の指定
モーダル上部で「現在時刻」か「時刻を指定」を選べます
紙記録の後入力など、遡って入力する際に活用してください
正常範囲（参考）
血圧：90〜140 / 40〜85　　脈拍：50〜100回/分
体温：35.5〜37.2℃　　SpO2：95%以上
⚠️ 範囲外の値は記録時に赤表示されます
🍚 食事・飲水
食事摂取量と水分摂取の記録
食事区分の選択
朝食 / 10時（おやつ）/ 昼食 / おやつ / 夕食　から選択
摂取量の入力
主食・副食はスライダーで 0〜10割 を選択
水分摂取量は mL で入力
🎤 音声入力例
「昼食 主食8割 副食7割 水分200」
「完食」「半分」「食欲なし 水分100」
💧 排泄記録
排尿・排便の状態を記録
種別と尿量
排尿 / 排便 / 両方　から選択
尿量：少量・普通量・多量　から選択
便性状
○ 普通便　△ 軟便　◇ 硬便　✕ 水様便
🎤 音声入力例
「排尿あり普通量」
「軟便あり 少量」
「失禁あり ポータブル使用」
📋 経時記録
出来事・ケア内容の記録
カテゴリと重要度
カテゴリは複数選択可（医療・転倒・行動・ケア など）
重要度：通常 / 重要 / 緊急　を選択
AI 報告先提案
内容を入力すると、AIがキーワードを解析して報告先（医師・看護師など）を自動提案します
提案はあくまで参考です。必要に応じて手動で変更してください

📅 スケジュール
施設・個別・訪問介護の予定管理
3つのビュー
全体：週間カレンダーで施設全体の予定を一覧表示
個別：利用者ごとのスケジュール（通院・入浴・リハビリなど）
訪問介護：日別ガントチャートで訪問予定を時系列確認
予定の追加
右下の ＋ ボタン をタップ → 利用者・日時・種別を入力して保存
🎤 口頭入力も可能：「山田さんの通院、明日10時から」のように話しかける
📌 タスク管理
事業所・担当者別のタスク割り当てと進捗管理
タスクの追加
右上の「＋ 追加」ボタンからタスクを登録します
タイトル・事業所・担当者・期限・メモを設定できます
タスクはFirebaseでリアルタイム同期され、全端末で共有されます
フィルター機能
事業所フィルター：全施設 / 居住 / デイ / 小多機 / 訪問 で絞り込み
担当者フィルター：登録スタッフ名で絞り込み
ステータスフィルター：全て / 未完了 / 完了 で絞り込み
タスクの完了・削除
タスクカードの「✓ 完了」ボタンをタップすると完了済みになります（取り消し可）
削除の権限：
統括管理者：全タスクを削除可
各事業所管理者：担当事業所のタスク、または自分が作成したタスクのみ削除可
一般スタッフ：削除不可
事業所管理者のデフォルト表示
各事業所管理者ロールでログインすると、担当事業所が自動的にフィルタリングされて表示されます
⚙️ 設定・管理
アカウント・権限・セキュリティ設定
権限の種類（3段階）
統括管理者　全機能・全データにアクセス可。スタッフ管理・設定変更など全権限を持つ
各事業所の管理者ロール（担当事業所のタスク管理・月次・改善提案が使える）：
サ高住管理者 デイ管理者 小多機管理者 訪問管理者 居宅管理者
一般スタッフ　記録入力・閲覧のみ。設定変更・削除は不可
パスワード変更（全職員）
設定 → 「パスワード変更」：現在のPW確認後に新しいPWへ変更
英字と数字を含む6文字以上が必要
統括管理者 専用機能
職員アカウント管理：有効化・停止・ID/PW変更・ロール割り当て（ロール一覧から選択するだけで担当事業所も確定）
アクセス制限：端末制限（登録端末のみ許可）・Wi-Fi制限（施設内のみ許可）
アカウント別履歴：職員ごとのログイン・操作履歴を閲覧
データバックアップ：全データをJSONでダウンロード。週1回の実施を推奨
❓ よくある質問
Q&A
ログイン
Q: パスワードを忘れた
A: 管理者（山田）に連絡してください。設定 → 職員アカウント管理からリセットできます
Q: 「端末未承認」と表示される
A: 端末制限が有効です。管理者に端末承認を依頼してください
Q: 「ネットワーク外」と表示される
A: Wi-Fi制限が有効です。施設のWi-Fiに接続してからログインしてください
記録入力
Q: 過去の日時で入力したい
A: 入力モーダル上部の「時刻を指定」を選択して、実施日時を手動入力してください
Q: 音声入力が反応しない
A: ブラウザへのマイク使用許可を確認してください。設定 → サイト設定 → マイク
データ・同期
Q: 別の端末でデータが反映されない
A: Firebaseでリアルタイム同期しています。ページを再読み込みしてください
Q: データが消えた
A: バックアップJSONから復元できます。管理者に連絡してください
その他
Q: アプリを改善してほしい
A: 左メニューの「💡 改善提案」から提案を送れます。管理者が確認して対応します
