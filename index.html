🔑 ログイン・ログアウト
アプリの使い始めと終わり方
ログイン手順
① 職員ID（4桁の数字）を入力
② パスワードを入力 → 「ログイン」をタップ
③ 初期パスワードは 職員IDと同じ です。ログイン後すぐに設定から変更してください
ログアウト・自動ロック
ログアウトは 設定 → 「ログアウト」ボタン
10分間操作がないと 自動ロック されます（8分で警告表示）
端末を離れる際は必ずログアウトしてください
パスワード変更
設定 → 「パスワード変更」から個人で変更できます
新しいパスワードは 英字と数字を含む6文字以上 が必要です
🏠 ホーム画面
最初に表示されるダッシュボード
🏢 事業所から入力（新機能）
ダッシュボード上部の紺色カードから サ高住・小多機・デイ・訪問介護 を選んでタップ
選択した事業所の利用者一覧が開き、そのままサービスが選択済みの状態で記録入力できます
例：デイ出勤時 → 「☀️ デイ」タップ → 利用者選択 → バイタル・食事入力
バイタル未記録アラート
本日バイタルが未記録の利用者数を赤い数字で表示
タップすると対象の利用者一覧にジャンプします
重要・緊急の申し送り
直近7日間の「重要」「緊急」申し送りを自動表示
🚨 赤 = 緊急　⚠️ オレンジ = 重要
クイックアクセス
利用者一覧 / スケジュール / 申し送りボード / 業務日誌 へのショートカット
👥 利用者一覧・詳細
利用者情報の確認と記録入力
一覧の使い方
利用者はあいうえお順で表示。上部の検索バーで名前・かなで絞り込めます
カードをタップ → 詳細画面へ移動
今日のサービスを選択（新機能）
詳細画面の「記録入力」エリアに サ高住 / 小多機 / デイ / 訪問介護 のサービスボタンがあります
今日利用するサービスをタップして選ぶと、そのサービス用の入力ボタンが表示されます
登録済みサービスは濃く、未登録は薄く表示されます（タップは常時可能）
⚙ サービス設定（新機能）
サービスボタン右端の ⚙ をタップ → 利用するサービスをチェックして保存
小多機は「通い・泊まり・訪問」を包括するサービスです。デイサービスとは別に登録してください
記録ボタン（サービス別）
サ高住：バイタル / 食事・飲水 / 排泄 / 経時記録 / 体重 / 申し送り
小多機・デイ：上記＋来所/退所
訪問介護：訪問介護記録 / 経時記録 / 申し送り
バイタルサマリー
異常値は 赤字 で表示されます
正常範囲：血圧 90〜140 / 40〜85　脈拍 50〜100　体温 35.5〜37.2℃　SpO2 95%以上
フェイスシート
右上「📋 フェイスシート」ボタンで既往歴・緊急連絡先・担当医などを確認・編集できます
🌡️ バイタル入力
血圧・脈拍・体温・SpO2の記録
入力項目
収縮期血圧 / 拡張期血圧 / 脈拍 / 体温 / SpO2 / 意識レベル
空欄でも保存できます（測定できなかった項目はそのままで）
🎤 音声入力の使い方
「音声で一括入力」ボタン → マイクに向かって話すだけで自動入力
例：「血圧130の80 脈拍72 体温36.5 SpO2 98 清明」
実施日時の指定
モーダル上部で「現在時刻」か「時刻を指定」を選べます
紙記録の後入力など、遡って入力する際に活用してください
正常範囲（参考）
血圧：90〜140 / 40〜85　　脈拍：50〜100回/分
体温：35.5〜37.2℃　　SpO2：95%以上
⚠️ 範囲外の値は記録時に赤表示されます
🍚 食事・飲水
食事摂取量と水分摂取の記録
食事区分の選択
朝食 / 10時（おやつ）/ 昼食 / おやつ / 夕食　から選択
摂取量の入力
主食・副食はスライダーで 0〜10割 を選択
水分摂取量は mL で入力
🎤 音声入力例
「昼食 主食8割 副食7割 水分200」
「完食」「半分」「食欲なし 水分100」
💧 排泄記録
排尿・排便の状態を記録
種別と尿量
排尿 / 排便 / 両方　から選択
尿量：少量・普通量・多量　から選択
便性状
○ 普通便　△ 軟便　◇ 硬便　✕ 水様便
🎤 音声入力例
「排尿あり普通量」
「軟便あり 少量」
「失禁あり ポータブル使用」
📋 経時記録
出来事・ケア内容の記録
カテゴリと重要度
カテゴリは複数選択可（医療・転倒・行動・ケア など）
重要度：通常 / 重要 / 緊急　を選択
AI 報告先提案
内容を入力すると、AIがキーワードを解析して報告先（医師・看護師など）を自動提案します
提案はあくまで参考です。必要に応じて手動で変更してください
申し送りへの転記
「申し送りにも転記する」にチェックを入れると申し送りボードにも同時反映されます
📣 申し送りボード
部署間の引き継ぎ情報を管理
ボードの構成
🩺 医師から　👩‍⚕️ 看護師から　🏠 サ高住から　🏡 小多機から　☀️ デイから　🚗 訪問介護から
各セクションの「＋ 追加」ボタンから申し送りを投稿できます
緊急度の色分け
🚨 緊急　⚠ 重要　📌 通常
利用者個別の申し送り
利用者詳細 → 「申し送り」タブから個別に確認・追加できます
📋 業務日誌・帳票出力
日次記録・帳票プレビュー・印刷
4つのサービスタブ
🏠 サ高住　🏡 小多機　☀️ デイ　🚗 訪問介護 のタブを選択して帳票カードを表示
日付ナビゲーターで対象日を選択できます（◀▶で前後の日へ）
帳票一覧
サ高住：業務日誌 / 個人記録（月次）/ 夜間日誌 / 曜日別利用票
小多機：業務日誌 / 個別記録（月次）
デイ：業務日誌 / デイ利用者状況
訪問介護：訪問介護業務日報 / 訪問介護記録（月次）
👁 プレビュー → 🖨 印刷
各帳票カードの「👁 プレビュー」をタップするとA4フルスクリーンで表示されます
月次帳票（個人記録・訪問介護記録）は利用者選択と月指定が必要です
プレビュー画面の「🖨 印刷」ボタンから直接印刷・PDF保存ができます
訪問介護 入力リスト
訪問介護タブ下部に当日の訪問記録一覧と「＋ 追加」ボタンがあります
入力した記録は「訪問介護業務日報」帳票に自動的に反映されます
📅 スケジュール
施設・個別・訪問介護の予定管理
3つのビュー
全体：週間カレンダーで施設全体の予定を一覧表示
個別：利用者ごとのスケジュール（通院・入浴・リハビリなど）
訪問介護：日別ガントチャートで訪問予定を時系列確認
予定の追加
右下の ＋ ボタン をタップ → 利用者・日時・種別を入力して保存
🎤 口頭入力も可能：「山田さんの通院、明日10時から」のように話しかける
⚙️ 設定・管理
アカウント・セキュリティ設定
パスワード変更（全職員）
設定 → 「パスワード変更」：現在のPW確認後に新しいPWへ変更
英字と数字を含む6文字以上が必要
管理者専用機能
職員アカウント管理：有効化・停止・ID/PW変更

データバックアップ：全データをJSONでダウンロード。週1回の実施を推奨
❓ よくある質問
Q&A
ログイン
Q: パスワードを忘れた
A: 管理者（山田）に連絡してください。設定 → 職員アカウント管理からリセットできます
Q: 「端末未承認」と表示される
A: 端末制限が有効です。管理者に端末承認を依頼してください
Q: 「ネットワーク外」と表示される
A: Wi-Fi制限が有効です。施設のWi-Fiに接続してからログインしてください
記録入力
Q: 過去の日時で入力したい
A: 入力モーダル上部の「時刻を指定」を選択して、実施日時を手動入力してください
Q: 音声入力が反応しない
A: ブラウザへのマイク使用許可を確認してください。設定 → サイト設定 → マイク
データ・同期
Q: 別の端末でデータが反映されない
A: Firebaseでリアルタイム同期しています。ページを再読み込みしてください
Q: データが消えた
A: バックアップJSONから復元できます。管理者に連絡してください
その他
Q: アプリを改善してほしい
A: 左メニューの「💡 改善提案」から提案を送れます。管理者が確認して対応します
🔑 AI FAQを使うにはAnthropicのAPIキーが必要です。
設定画面 →「AI FAQ APIキー」に入力してください。
APIキーは端末内にのみ保存されます。
